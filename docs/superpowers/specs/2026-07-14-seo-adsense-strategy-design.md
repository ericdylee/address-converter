# SEO + 애드센스 재승인 전략 설계

- **작성일:** 2026-07-14
- **대상:** address-converter.com (한글·일본 주소 → 영문 변환기)
- **한 줄 요약:** 애드센스가 "저품질 콘텐츠"로 거절 → 콘텐츠 깊이·신뢰 신호·기술 SEO를 한 번에 올려 재승인과 검색 트래픽을 동시에 확보한다.

---

## 1. 목표와 제약 (인터뷰로 확정된 내용)

| 항목 | 결정 |
|------|------|
| **최종 목표** | 광고 수익 → 전략 원칙 = "관련 검색 유입 총량 최대화" |
| **현재 블로커** | 구글 애드센스 **거절됨**, 사유 = **"가치가 낮은 콘텐츠(Low value content)"** |
| **콘텐츠 방침** | 양치기 X. **질 좋은 글 몇 편**에 집중 (초안은 Claude가 쓰고 대표가 검토) |
| **측정 현황** | Google Search Console **등록은 됨** (데이터 아직 얕음) · 사이트 내 애널리틱스 **없음(깜깜이)** |
| **선택한 접근** | **B안 — 제대로 한 번에.** 애드센스 재승인 + SEO를 하나의 프로젝트로 처리 |

**핵심 통찰:** 목표(광고 수익)와 블로커(저품질 거절)를 푸는 열쇠가 동일하다 — "진짜 유용하고 두툼한, 완성된 사이트". 콘텐츠를 안 건드리는 어떤 전략도 반쪽짜리다.

---

## 2. 진단: 왜 "저품질 콘텐츠"로 보였나

현재 가이드는 형편없지 않다(표·예시·6섹션 구조 보유). 그러나 애드센스 기준·SEO 경쟁력 관점에서 세 가지가 약하다.

1. **사이트 전체가 작다** — 변환기 1개 + 가이드 5편 + FAQ/소개. "완성된 사이트"보다 "위젯 + 짧은 글 몇 개"로 보인다.
2. **글이 짧다** — 편당 실본문 약 400~500단어. 상위 노출·애드센스 통과엔 편당 **800~1,200단어의 실질 유용 콘텐츠**가 필요.
3. **독창성·전문성(E-E-A-T) 신호가 약하다** — 강력한 무기인 **"행정안전부 공식 API 기반"**이 전면에 드러나지 않는다.

---

## 3. 현재 사이트 자산 (변경 출발점)

**이미 잘 되어 있는 것 (유지):**
- 홈(한국+일본 변환기), 가이드 5편(english-address, overseas-shopping, japan-address, common-mistakes, korea-region-names), FAQ/소개/문의/개인정보/404
- `app/sitemap.ts`, `app/robots.ts` (`/api`·`/result` 제외 — 올바름)
- 완전한 메타데이터(title 템플릿, OG/트위터, canonical, keywords), 페이지별 OG 이미지
- 네이버 사이트 소유확인, FAQ 페이지의 FAQPage JSON-LD

**비어 있는 것 (이번 작업 대상):**
- 사이트 내 애널리틱스 전무
- 가이드/홈/브레드크럼 JSON-LD 없음(FAQ만 있음)
- 콘텐츠 깊이·독창성 부족
- 신뢰 신호(공식 데이터 출처) 부각 안 됨

---

## 4. 전략 설계 — 3개 작업 흐름

### 흐름 1 — 콘텐츠 두툼하게 (애드센스 0순위 + SEO 핵심)
- **기존 5편 심화:** 각 800~1,200단어로. 실전 시나리오, 예외 케이스, 국가별 팁, 글마다 미니 FAQ, "왜 그런지" 설명을 추가해 독창성 강화.
- **신규 고수요 가이드 3~4편:** 검색량 조사 후 확정. 후보 주제 — 해외 쇼핑몰별 주소 입력법(아이허브/아마존/알리 등), 여권·비자 영문주소, 영어 이름 표기법.
- **홈페이지 본문 보강:** 위젯 위주 → "이 도구가 뭐고 왜 필요한지 + 동작 원리 + 미니 FAQ"를 본문으로 추가해 랜딩 자체에 알맹이 부여.

### 흐름 2 — 기술 SEO 토대
- **구조화 데이터(JSON-LD):** 가이드 = Article/HowTo, 홈 = SoftwareApplication, 전 페이지 = BreadcrumbList. (FAQPage는 이미 있음.)
- **측정 도구 설치:** 기본값 = **Vercel Analytics**(이미 Vercel 배포 중 → 설치 한 줄, 개인정보 부담 적음, 비개발자 친화적). 유입 검색어는 서치콘솔이 담당하므로 이 조합으로 충분. (전환·퍼널 등 심화 분석이 나중에 필요해지면 PostHog로 확장 — 이번 범위엔 미포함.)
- **서치콘솔 점검:** sitemap 제출 확인, 색인 상태·유입 검색어 모니터링 루틴화.
- **내부 링크:** 가이드끼리 + 가이드→도구를 서술형 앵커텍스트로 연결. 신규 페이지는 sitemap에 반드시 추가.

### 흐름 3 — 신뢰·완성도 신호 (E-E-A-T)
- **소개 페이지 강화:** 누가 왜 만들었는지 + **"행안부 공식 데이터 기반"을 신뢰 신호로 부각**.
- 문의·개인정보 유지, 빈/깨진 페이지 없이 전체 완성도 통일.

---

## 5. 진행 순서

1. **콘텐츠 심화 + 신뢰 신호 + 신규 가이드** → 거절 사유 직격 (최우선)
2. **병행: 기술 SEO**(측정 도구·JSON-LD·내부 링크)
3. **그다음: 애드센스 재신청** — 충분히 개선된 뒤에만
4. **이후: 반복 개선** — 서치콘솔·애널리틱스 데이터 보며 다듬기

> 참고: "저품질 콘텐츠" 거절은 고정 대기기간이 없고, **실질적으로 개선된 뒤** 재신청하는 것이 원칙. 어설픈 재신청은 재거절 위험 → 순서 1·2를 충분히 마친 뒤 3으로 간다.

---

## 6. 성공 기준

- **애드센스:** 재심사 통과(승인).
- **SEO:** 주요 타깃 검색어로 색인·노출 증가(서치콘솔 impressions 상승으로 측정).
- **측정:** 애널리틱스로 유입·페이지뷰를 실제로 추적 가능해짐(깜깜이 해소).

---

## 7. 범위 밖 (YAGNI)

- 가이드 20~30편 대량 생산(대표 방침: 질 좋은 몇 편).
- 유료 SEO 툴 도입, 백링크 구매, 외부 광고 집행.
- 변환기 기능 자체의 신규 개발(이번 전략은 SEO·콘텐츠·신뢰에 집중).
